held-out splits predate the system they test (see git history).

ListOps splits: train 60 / id 40 / para 40 / oog 20. Only `train` may be used to
build lexicons, n-gram tables or few-shot exemplars. Expected outputs are computed
by the independent Python `reference_eval` (or hand-written reference solutions for
`oog`), never by the TypeScript compiler under test.

**Known bias:** the `id` and `para` splits are written by the same agent that
wrote the parser, in a DSL chosen by that agent. They measure in-domain coverage,
not general coding ability. HumanEval is the externally-authored check.
